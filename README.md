# Песочница 1С

Компилятор встроенного языка 1С в JavaScript, запросы к демо-базе, конструктор запросов, формы и печатные формы — прямо в браузере, без установки платформы. Весь сайт — один файл `index.html`.

Открыть: https://roman33r.github.io/1Comp/

## Тесты ядра

```bash
node --test
```

Независимый учебный проект. «1С» и «1С:Предприятие» — товарные знаки фирмы «1С»; проект с ней не связан.
